\begin{frame}{The pipeline: one seed-0 scoring run $\to$ selection $\to$ three training recipes}

    \begin{block}{Scoring --- a single, compute-matched \emph{hard-label} run at seed 0 [B8]}
    \tiny
    Every trajectory score comes from \emph{one} full-dataset HL run whose length is \emph{compute-matched}
    to a downstream run on the coreset [HT Sec.5] --- a bigger budget just buys a longer scoring run:
    \vspace{-0.12cm}
    $$K \;=\; \frac{300\cdot\mathrm{IPC}\cdot n_{cls}}{N} \;=\; 6\,/\,30\,/\,60\ \text{epochs (IPC 10/50/100)},
    \qquad \text{StepLR}@\,\mathrm{round}(K\cdot 151/300).$$
    \vspace{-0.4cm}
    \begin{itemize}\setlength\itemsep{1pt}
        \item \textbf{One instrumented pass logs, per epoch:} the EL2N score
              $S_k=\lVert\mathrm{softmax}-\mathrm{onehot}\rVert_2\in\mathbb{R}^{K\times N}$, the fp16 softmax
              trajectories $P\in\mathbb{R}^{K\times N\times C}$, and the frozen teacher soft labels $q$.
        \item \textbf{CAD} [HT Eq.1--2]: sliding-window uncertainty $U_k=\mathrm{std}\big(S_{k..k+J-1}\big)$;
              $\mathrm{CAD}=\mathrm{mean}$ of the last $W{=}2$ windows, with $J=K{-}W$ so the windows span the
              entire run.
        \item \textbf{Selection is a pure function of this run:} CAD-Prune, SHARP, R-CAD read $S,P,q$ directly;
              EL2N-Best instead uses a \emph{separate} 10-seed epoch-20 EL2N mean [B3]. The chosen subset is
              fixed \emph{once per IPC} and reused, unchanged, across all three columns ([HT] convention).
    \end{itemize}
    \end{block}

    \vspace{-0.1cm}
    \begin{block}{The three training recipes (column groups) --- reproduced verbatim by the code}
    \tiny
    \begin{itemize}\setlength\itemsep{1pt}
        \item \textbf{HL} --- one-hot cross-entropy [HT Tab.4]: SGD $10^{-2}$, momentum 0.9, wd $5{\times}10^{-4}$,
              batch 256, MultiStepLR@151 ($\gamma{=}0.1$), 300 epochs, DSA.
        \item \textbf{SL} --- \emph{fixed} per-image teacher soft label $q=\mathrm{softmax}(\mathrm{obs}(x)/T)$,
              KL at $T{=}20$: AdamW $10^{-3}$, cosine, 300 epochs, batch 256, DSA.
        \item \textbf{KD+SL} --- RDED's official validation code, run \emph{unmodified} [B1]: on-the-fly teacher
              soft labels on cutmix batches, KL $T{=}20$, AdamW quarter-cosine, 300 epochs, RDED's official
              batch/lr (incl.\ the hidden \texttt{cifar100-conv3} override bs 25, lr $2{\times}10^{-3}$).
    \end{itemize}
    \end{block}

\end{frame}

\begin{frame}{Our methods: R-CAD \& SHARP --- one coverage selector, two demand weights}

    \begin{block}{The shared engine --- demand-weighted coverage of each class}
    \tiny
    Per class $c$, over the full candidate pool $P_c$ (500 images), build a cosine kernel on
    L2-normalized observer penultimate features, $\kappa(i,j)=\max\!\big(0,\cos(\hat\varphi_i,\hat\varphi_j)\big)$,
    and pick the budget-$b$ subset by \textbf{weighted facility location}:
    \vspace{-0.15cm}
    $$A_c^{*} \;=\; \arg\max_{A\subset P_c,\ |A|=b}\ \sum_{i\in P_c} w_i\cdot\max_{j\in A}\kappa(i,j)$$
    \vspace{-0.4cm}

    Monotone submodular $\Rightarrow$ greedy carries the $(1-1/e)$ guarantee (Nemhauser et al., 1978) ---
    effectively exact and instant at $|P_c|=500$. \textbf{Reading:} every pool image demands to be
    \emph{represented} by a similar selected exemplar; $w_i$ sets how loudly image $i$ demands it.
    \end{block}

    \vspace{-0.1cm}
    \begin{columns}[t]
        \begin{column}{0.5\textwidth}
            \begin{block}{R-CAD --- difficulty demand: $w_i=\mathrm{CAD}_i$}
            \tiny
            \begin{itemize}\setlength\itemsep{1pt}
                \item CAD-Prune ranks each image \emph{in a vacuum}; under a tiny budget it spends picks on
                      near-duplicates of the same difficult mode.
                \item R-CAD makes the decision \emph{set-level}: keep images that are individually
                      informative (high CAD) \emph{and} jointly non-redundant.
                \item Two poles: drop coverage $\to$ CAD-Prune; set $\mathrm{CAD}_i\equiv 1$ $\to$
                      K-centers. R-CAD is the difficulty-weighted interior.
            \end{itemize}
            \end{block}
        \end{column}
        \begin{column}{0.5\textwidth}
            \begin{block}{SHARP --- alignment demand: $w_i = z_c(A_{\text{grad}})_i$ (shifted $\geq 0$)}
            \tiny
            \begin{itemize}\setlength\itemsep{1pt}
                \item {[HT Sec.3]}: soft labels \emph{homogenize} sample influence; hard labels stay
                      quality-sensitive $\Rightarrow$ keep images whose hard label \emph{already behaves
                      like soft-label training}.
                \item Statically the signal collapses: $(p-y)-(p-q)=q-y$ = teacher confidence (RDED's own
                      criterion). Along the trajectory, last-layer gradients factor through the features, so
                      $\cos(\nabla\ell_{HL},\nabla\ell_{SL})\big|_{\theta_k}=\cos(p_k-y,\ p_k-q)$.
                \item $A_{\text{grad}}(i)=\tfrac{1}{K}\sum_{k}\cos\big(p_k(i)-y_i,\ p_k(i)-q_i\big)$ over
                      the $K$ scoring epochs (identity verified incl.\ bias, \texttt{sharp.py} selftest 1).
            \end{itemize}
            \end{block}
        \end{column}
    \end{columns}

    \vspace{0.05cm}
    {\tiny \textbf{One line:} same coverage selector, different demand --- they disagree only on which
    images most deserve to be covered. The \textbf{-2D} variants run the identical selection at RDED's pool
    budget (mipc 300), then RDED's stock crop/select/stitch. Both reuse the cached seed-0 scoring run ---
    no extra training; the comparison with CAD-Prune is compute-exact.}

\end{frame}
